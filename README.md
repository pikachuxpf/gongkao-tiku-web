# 公考题库

> 公务员 / 事业单位考试题库，含题干、参考答案、答题演示、考点。

## 项目来源与致谢

本项目基于 [zzcc-nb/gongkao-tiku](https://github.com/zzcc-nb/gongkao-tiku) 仓库进行二次开发，在其题库和相关资料的基础上，增加了墨卷练习工作台、题库索引构建、刷题进度、收藏/错题管理、离线自评以及 OpenAI 兼容大模型辅助能力。

感谢 [zzcc-nb/gongkao-tiku](https://github.com/zzcc-nb/gongkao-tiku) 项目作者提供题库、参考答案、答题演示及相关整理工作，为本项目的学习工具开发提供基础数据支持。

## 墨卷练习工作台

仓库现在包含一个可直接运行的 Vite Web 应用：

- `npm install` 安装依赖
- `npm run dev` 启动本地练习工作台
- `npm run build` 重新扫描 Markdown 题库并生成生产包
- `npm test` 校验题库数量和生成的题目索引

打开后可以从今日书桌开始刷题，按科目、题型、题目形式和关键词筛选；主观题支持答案草稿、离线要点自评、参考答案/答题演示、收藏和错题回看。设置页支持保存 OpenAI 兼容接口地址、模型名和 Key，交卷后可请求模型进行语义评分、缺漏点分析和改写建议；选择题数据加入后会自动显示选项、答案解析和模型解析入口。

### 数据增量添加

题库源文件仍然使用原有 Markdown 格式，放入 `申论题库/` 或 `综应题库/` 对应分类目录即可。构建脚本会跳过目录 README，识别以下分区：

```text
# 题目标题
> 元数据
## 📌 题目
## 📖 给定材料
## ✅ 参考答案
## 🎓 答题演示
```

`npm run build:data` 会把源文件转换为 `public/data/index.json` 和按题目拆分的 JSON 文件。生成数据默认不提交 Git，迁移到新环境时运行 `npm install` 后执行 `npm run dev` 或 `npm run build` 即可重建。

> 数据来源：粉笔题库（个人备考用）。
