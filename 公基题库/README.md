# 事业编公基真题

本目录收录来自 [linfukai186-arch/gongkao-tiku](https://github.com/linfukai186-arch/gongkao-tiku) 的事业编公基公开真题数据，按年份拆分为 `真题/y年份.json`，便于后续增量添加。

## 数据格式

每个年份文件的外层 key 是试卷名称，题目字段为：

- `t`：模块分类
- `s`：细分题型
- `q`：题干
- `o`：选项数组
- `a`：答案
- `e`：官方解析

运行 `npm run build:data` 后，系统会将这些 JSON 转换为统一题目索引，并保留上游数据中的模块和细分题型。当前真题文件的模块字段主要为政治理论、常识判断；后续新增数据如果包含法律基础、经济管理、公文写作、科技人文等分类，系统会自动显示。新增年份时放入 `真题/` 并保持 `yYYYY.json` 命名即可。
